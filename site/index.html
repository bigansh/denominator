What we hold to

Three rules, applied to everything we publish

RULE 01

Compute it, don’t assert it

No score is published until the full country-by-indicator matrix exists and the arithmetic runs end to end. Where the data cannot support a number, we say so and leave the cell empty rather than filling it with something plausible.

RULE 02

State the denominator

A country percentile and a population percentile answer different questions. We compute both, print both, and name which one a given claim rests on. A composite that hides this is a composite you cannot check.

RULE 03

Ship the workings

Everything comes with the live data behind it — inputs editable, sources attached, results recalculating from the file itself. Provenance is stated per value, including which are published data and which are modelled.

Shared method

How a Denominator score gets built

The same six steps run behind every composite score, so results are comparable across the catalogue and any one of them can be re-derived from the published data. A dataset that isn’t a score still follows the three rules above — sourced, checkable, nothing asserted — without necessarily this exact pipeline.

01

Assemble the matrix first

Countries enter the sample only if every indicator can be populated at reasonable confidence. Partial coverage means exclusion, not imputation — except where an imputation is modelled explicitly, reported with its fit, and flagged row by row.

02

Normalise against winsorised bounds

Each indicator is clipped at the 5th and 95th sample percentile, then rescaled 0–100 and inverted where lower is better. Clipping stops one extreme country from compressing everyone else into a narrow band.

03

Aggregate through named dimensions

Indicators roll into dimensions, dimensions into blocks, blocks into the index. Every weight is stated and editable. Nothing enters the total except through a dimension someone can argue with.

04

Rank twice

Once with each country as one unit, once with each country weighted by the population the index is about. Both percentiles are published side by side.

05

Test the weights

Results are re-run under equal weighting, dimension swaps, dropped dimensions, unclipped normalisation and z-scores. If a headline moves materially, it is reported as a range rather than a point.

06

Publish the limits with the result

Which indicators are proxies, which were dropped for coverage, which values are reconstructions. The caveats sit in the same document as the number, not in an appendix nobody opens.

The colour scale

One ramp carries score across every chart, table and map in the catalogue. Low is plum, high is deep teal. It never means anything else.

050100
Two scores, always

Where an index measures both a present state and a future one, they are kept apart and weighted evenly, so a country with a comfortable present and a poor launchpad cannot hide behind a single average.
